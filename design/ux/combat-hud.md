## HUD Philosophy

전투 HUD는 평소에는 시야를 방해하지 않는 하단 주변시 정보층으로 유지한다. 체력은 생존 판단을 위해 가장 크게, 마나·주문 쿨다운은 자원 판단을 위해 중앙 하단에, 대시와 텐션은 각각 회피와 전투 모멘텀 판단을 위해 양쪽에 배치한다.

전투가 오버드라이브에 들어가면 HUD는 정보를 늘리지 않고 오히려 단순화한다. 마나와 쿨다운은 ∞ 표기로 접고, 텐션 위치는 남은 시간 타이머로 전환하며, 크림슨 색·패턴·펄스로 “규칙이 바뀐 상태”를 즉시 전달한다. 모든 요소는 0.2초 안에 곁눈질로 읽혀야 하며, 게임플레이 입력이나 판정을 소유하지 않는다.

## Information Architecture

### Full Information Inventory

Combat HUD는 아래 정보를 읽기 전용으로 표시한다. 모든 데이터의 진실원은 상류 게임플레이 시스템이며, HUD는 입력이나 판정을 소유하지 않는다.

| 정보 | 원본 시스템 | 표시 목적 |
|---|---|---|
| Health / MaxHealth | Health/Damage Core | 생존 판단 |
| Low-health 상태 | Health/Damage Core | 즉각적인 위험 경고 |
| Mana / MaxMana | Spell Casting | 주문 사용 가능 자원 판단 |
| 3개 주문의 쿨다운 | Spell Casting | 다음 행동 선택 |
| Current Dash Charges | Dash/Evasion | 회피 가능 여부 판단 |
| Tension 값 및 Building/Decaying 상태 | Combo/Tension Gauge | 오버드라이브까지의 모멘텀 판단 |
| Overdrive 잔여 시간 | Luna Overdrive | 강화 상태의 남은 기회 판단 |
| Executable 대상 및 근접 가능 상태 | Core Extraction Execution | 처형 기회 인지 |

### Categorization

| 정보 | 분류 | 표시 규칙 |
|---|---|---|
| 체력 + 저체력 경고 | 항상 표시 | 좌하단의 가장 큰 생존 정보. 저체력은 비네트로 보조한다. |
| 마나 | 항상 표시 | 하단 중앙의 주문 자원 정보. 오버드라이브에서는 ∞로 전환한다. |
| 주문 3개 쿨다운 | 항상 표시 | 마나 인접 슬롯에서 각 주문의 준비 상태를 표시한다. 오버드라이브에서는 숨기고 ∞ 상태에 통합한다. |
| 대시 2회 충전 | 항상 표시 | 우하단에서 정수 핍과 충전 진행률을 표시한다. |
| 텐션 게이지 | 항상 표시 | 우하단에서 Building/Decaying/Charged 상태를 색·밝기·패턴·펄스로 함께 표시한다. |
| 처형 가능 프롬프트 | 상황별 | 대상 근처의 월드 마커와 화면 중앙부 근접 프롬프트를 표시한다. |
| 오버드라이브 타이머 | 상황별 | 오버드라이브 중 텐션 게이지 위치를 대체한다. |
| 저체력 비네트 | 상황별 | 체력이 임계값 아래일 때 화면 가장자리에만 표시한다. |
| 수치 텍스트 | 필요 시 | 기본 상태에서는 절제하고, HUD 크기·접근성 설정에 따라 강화한다. |

## Layout Zones

전투 시선이 화면 중앙에 머무르도록, 영구 HUD는 화면 하단의 세 구역에만 배치한다. HUD가 전투·파괴 이펙트·적 실루엣을 가리지 않아야 한다는 Art Bible의 `Player-character as focal anchor` 원칙을 따른다.

```text
┌────────────────────────────────────────────────────────────┐
│                                                            │
│                 [ 전투 / 월드 공간 ]                       │
│                                                            │
│          처형 가능 대상: 글리치 링 + 아이콘                │
│                                                            │
│                 [ F / 패드 버튼: 처형 ]                   │
│                                                            │
│ HP ━━━━━━━━━       MP ━━━━━  [●][●][●]       ◇◇  TENSION │
│ 저체력 경고         주문 쿨다운 3종          대시  텐션   │
└────────────────────────────────────────────────────────────┘
```

| 구역 | 배치 요소 | 설계 근거 |
|---|---|---|
| 좌하단 | 체력바, 저체력 경고 | 생존 판단은 가장 큰 주변시 정보여야 한다. |
| 하단 중앙 | 마나바, 블랙홀·화염·번개 쿨다운 슬롯 | 주문 자원과 다음 행동 선택을 하나의 시선 이동으로 읽는다. |
| 우하단 | 대시 충전 핍, 텐션 게이지 | 회피 가능 여부와 전투 모멘텀을 함께 판단한다. |
| 월드 공간 | 처형 대상의 글리치 링·아이콘 | 기회가 발생한 적의 위치를 직접 가리킨다. |
| 중앙 하단 | F 또는 활성 게임패드 버튼의 처형 프롬프트 | 가까운 처형 대상이 있을 때만 표시한다. |

오버드라이브 중에는 우하단의 텐션 게이지를 크림슨 잔여시간 타이머가 대체한다. 하단 중앙의 마나와 주문 쿨다운은 ∞ 표시로 단순화하여, 강화 상태에서 추적해야 할 정보량을 줄인다.

## HUD Elements

| 요소 | 분류 | 시각 형태 | 갱신 방식 | 상태 변화 |
|---|---|---|---|---|
| 체력 | 항상 표시 | 좌하단의 세로형 결정 파편 게이지 | Health 변경 이벤트 | 감소 시 짧은 균열·감쇠. 저체력에서는 화면 외곽의 저채도 비네트를 추가한다. |
| 마나 | 항상 표시 | 하단 중앙의 얇은 수평 바 | Mana 변경 이벤트 | 주문 사용 시 즉시 감소한다. 오버드라이브에서는 실수치 대신 ∞ 표시로 전환한다. |
| 주문 3종 | 항상 표시 | 마나바 인접의 각진 블랙홀·화염·번개 아이콘 슬롯 | 쿨다운 시작/종료 이벤트 및 활성 중 시간 스윕 | 준비 상태는 선명하게, 쿨다운 중에는 어두운 오버레이가 사라지는 방식으로 표시한다. |
| 대시 | 항상 표시 | 우하단의 2개 육각 핍 | 대시 충전 변경 이벤트 | 사용 시 핍이 비어지고, 충전 중인 핍 내부가 진행률만큼 채워진다. |
| 텐션 | 항상 표시 | 우하단의 분절된 반원형 아크 | 텐션 변경 이벤트 및 변동 중 표시 보간 | Building은 밝은 상승 흐름, Decaying은 어두운 해칭 패턴, 90% 이상은 펄스로 함께 구분한다. |
| 오버드라이브 | 상황별 | 텐션 위치를 대체하는 방사형 원형 타이머 | 시작/종료 이벤트 및 활성 중 시간 스윕 | 크림슨 팔레트, 방사형 카운트다운, 마지막 3초 펄스를 사용한다. |
| 처형 | 상황별 | 대상의 글리치 링·아이콘과 중앙 하단의 입력 글리프 | Executable 태그 및 근접 상태 이벤트 | 앰버 계열, 0.5초 펄스, 거리 조건 충족 시에만 화면 프롬프트를 표시한다. |

일반 전투 UI는 Lunar White와 Deep Blue를 기반으로 한 얇고 각진 형태를 사용한다. 오버드라이브만 원형·크림슨 형태로 전환하여, 정상 상태의 절제와 강화 상태의 폭발을 명확히 대비시킨다. 색상으로 전달하는 모든 의미는 형태·밝기·패턴·애니메이션 중 하나 이상으로 중복 전달한다.

## Dynamic Behaviors

| 상황 | HUD 반응 |
|---|---|
| 전투 시작·일반 상태 | 모든 항상 표시 요소를 낮은 강도로 유지한다. |
| 주문 사용 | 마나를 즉시 갱신하고, 해당 주문의 쿨다운 오버레이를 시작한다. |
| 대시 사용 | 핍 하나를 즉시 비우고 충전 진행 표시를 시작한다. |
| 텐션 상승 | 아크가 밝게 차오르며 상승 방향을 짧게 강조한다. |
| 텐션 감쇠 | 아크를 어둡게 하고 해칭 패턴으로 “지금 새고 있음”을 표시한다. |
| 텐션 90% 이상 | 실제 텐션 값 기준으로 즉시 펄스를 시작한다. 표시 보간값을 기준으로 지연시키지 않는다. |
| 저체력 | 결정 게이지의 균열을 강화하고 화면 가장자리에 비네트를 표시한다. 색상만으로 경고하지 않는다. |
| 처형 가능 | 모든 대상에 월드 마커를, 근접한 최근접 대상 하나에만 입력 프롬프트를 표시한다. |
| 오버드라이브 시작 | 텐션을 원형 타이머로 교체하고, 마나·쿨다운을 ∞로 단순화하며 HUD 액센트를 크림슨으로 전환한다. |
| 오버드라이브 종료·사망 | 일반 팔레트와 실제 자원 표시로 즉시 복귀한다. 처형 표시는 태그 소멸 즉시 제거한다. |

강한 플래시는 오버드라이브 진입에만 제한한다. 점멸은 초당 3회 이하, 회당 0.3초 이하로 유지하며, 오버드라이브 비네트는 설정에서 끌 수 있다.

## Platform & Input Variants

| 항목 | MVP 규칙 |
|---|---|
| 기본 플랫폼 | PC. 키보드·마우스를 기본 입력으로 한다. |
| 기본 화면 | 16:9, 1080p 기준. HUD는 화면 가장자리에서 5% 안쪽에 배치한다. |
| PC 게임패드 | HUD의 배치와 정보량은 바꾸지 않는다. 처형 프롬프트의 `F` 글리프만 활성 게임패드 버튼 글리프로 교체한다. HUD 자체는 포커스를 받지 않는다. |
| 확장성 | 모든 배치와 여백은 상대 앵커를 사용한다. 21:9와 향후 콘솔 세이프존을 고려하되, 콘솔 전용 재배치·인증 요구사항은 확정하지 않는다. |
| HUD 크기 | 1080p 기준 80%~150%로 조절한다. 150%에서도 하단 세 구역이 겹치지 않아야 한다. |

## Accessibility

- 1080p 기준 모든 HUD 텍스트는 최소 18px이며, 배경 대비는 최소 4.5:1을 유지한다.
- HUD 크기는 80%~150%로 조절한다.
- 텐션의 Building·Decaying·90% 이상 상태는 색상뿐 아니라 밝기, 해칭 패턴, 펄스로 구분한다.
- 오버드라이브는 크림슨 전환 외에도 원형 타이머, ∞ 표기, HUD 구조 변경으로 전달한다.
- 처형 기회는 앰버 계열 색상 외에 대상 글리치 링, 아이콘 테두리, 0.5초 펄스로 전달한다.
- 저체력은 색상 외에 결정 게이지의 균열과 화면 가장자리 비네트로 알린다.
- 오버드라이브 비네트와 카메라 흔들림은 설정에서 끌 수 있다. 해당 설정을 꺼도 게임플레이 판단에 필요한 정보는 사라지지 않는다.
- HUD는 비대화형이므로 키보드·게임패드 포커스 순서에 포함하지 않는다.
